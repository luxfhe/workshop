# Lux FHE Workshop

Interactive tutorials and exercises for learning FHE.

## Workshops

### 1. FHE Fundamentals (2 hours)
- What is FHE?
- Hands-on: First encrypted computation
- Lab: Build a private calculator

### 2. Private Machine Learning (3 hours)
- FHE for ML overview
- Hands-on: Train on encrypted data
- Lab: Private sentiment analysis

### 3. Private Agents (3 hours)
- AI agents with FHE
- Hands-on: Build encrypted context agent
- Lab: Private financial advisor

### 4. Private Smart Contracts (4 hours)
- FHE on blockchain
- Hands-on: Encrypted voting
- Lab: Private auction contract

## Setup

```bash
git clone https://github.com/luxfhe/workshop
cd workshop
pip install -r requirements.txt
jupyter lab
```

## Prerequisites

- Python 3.10+
- Basic cryptography knowledge
- Familiarity with one of: Python, Go, Rust, or TypeScript
